    Add "Sign in with Time" to your own website

    Your server makes a one-time challenge. The browser SDK opens the wallet in a window on the click, the person approves, and your server checks the signed answer against the chain before it starts its own session. The website never sees a password or a key.

    // On the click: the wallet window opens at once, the challenge follows.
const request = post('/api/login/challenge', {})
  .then(challenge => ({ type: 'login', challenge }));
const proof = await TimeSDK.requestWallet({ walletOrigin, request });
await post('/api/login/finish', proof);

    The server side of this page is client-v4/server-auth.mjs (the sign-in and the checks of a payment) and the routes in client-v4/server.mjs; client-v4/README.md says what they check. A payment works the same way, with a request of the type payment.

    Time test network: the seconds have no value. Signing in proves that you control the account; it gives this website no power to spend from it.
