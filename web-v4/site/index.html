Time

Time is a currency whose unit is the second. The network creates one second of currency for each second that passes on its chain, one for the whole network and not one per person, so the supply always equals the time since the network started.

This is a test network

  • The seconds here have no value. They cannot be bought, sold or exchanged for anything.
  • The network may be reset at any time, and everything on it erased.
  • The software has not had its outside audit yet.
  • The end date of this test network is not set on this page.
